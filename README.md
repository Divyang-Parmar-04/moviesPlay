# 🎬 MoviesPlay

MoviesPlay is a modern movie discovery and streaming aggregation web application built **strictly for entertainment and educational purposes**.  
It allows users to explore movies, view details, trailers, and access publicly available streaming sources using third-party APIs.

---

## 🚀 Features

- 🔍 Browse and discover movies
- 🎞️ View movie details, posters, and trailers
- 🌍 Location-based movie availability
- 📱 Fully responsive (Mobile, Tablet & Desktop)
- ⚡ Fast UI with smooth animations
- 🔐 First-visit disclaimer popup
- 📄 About, Disclaimer & Fair Use pages

---

## 🛠️ Tech Stack

### Frontend
- **React.js**
- **Tailwind CSS**
- **Redux Toolkit**
- **Framer Motion**
- **React Router**

### APIs & Data Sources
- **TMDB API** – Movie metadata, posters & information
- **VidAPI** – Streaming source aggregation
- **CinemaOS** – Streaming data provider
- **MoviesAPI** – Additional movie data services

---

## ⚠️ Disclaimer

MoviesPlay does **not host, upload, store, or distribute** any movies or copyrighted content on its own servers.

All movie-related content and streaming links are fetched from **publicly available third-party APIs** available on the internet.

MoviesPlay **does not support or promote piracy** in any form.

If you are a copyright owner and believe your rights are affected, please contact the respective third-party content providers.

---

## ⚖️ Fair Use Policy

MoviesPlay uses movie metadata, posters, and related information under **fair use principles** for:
- Educational purposes
- Movie discovery
- Non-commercial demonstration

All data usage follows the terms and policies of the respective API providers.
